Reading a domain's content requires readership of that domain — a different authority from host administration (ADR 0077). Being the operator lets you administer the host, not read residents' content; in this single-operator instance the operator reads every domain only because they are all its own. Content is returned in cleartext over the local connection, so it is only as private as your access mode: keep it to loopback or ingress until TLS exists.

Crypto-shred a privacy domain

Destroying a domain's keys is irreversible. Every memory item in that domain becomes unreadable, including copies in existing backups. There is no undo and no recovery. Requires memory encryption to be enabled; without it the content is plaintext at rest and shredding would protect nothing.
