# Trademark and Naming Policy

This policy protects Pico users from misleading names, compatibility claims and official-service claims.

It is separate from the software license. The software license does not grant trademark, brand, endorsement or official-service rights.

## Protected names

The following names are treated as Pico project names or product identifiers:

- Pico
- Pico Home
- Pico Home Core
- Pico Home Managed
- Pico Vault
- Pico Surface
- Pico Relay
- Pico Link
- Pico Home Link
- Origin Light

This list may grow as the project matures.

## Descriptive use

You may use Pico names to truthfully describe the project, for example:

- "built with Pico"
- "compatible with Pico Link version X"
- "uses the Pico Home Link protocol"
- "forked from Pico"

Descriptive use must be accurate and must not imply official status, endorsement, certification, commercial permission or project ownership.

## Official use

You may not present a fork, hosted service, derivative work, package, app, cloud service, managed service or commercial offer as official Pico unless you have explicit permission from the designated Pico rights holder.

Do not use names such as:

- Official Pico
- Official Pico Home
- Pico Home Managed
- Pico Cloud
- Pico Hosting
- Pico Certified

unless you have permission.

## Fork naming

Forks should use a clearly distinct name.

Acceptable examples:

- "Example Assistant, forked from Pico"
- "Example Home, compatible with Pico Home Link version X"
- "Example Relay for Pico-compatible clients"

Avoid names that make the fork look official, such as:

- Pico Pro
- Pico Cloud
- Pico Plus
- Pico Managed
- Pico Enterprise
- Better Pico
- Pico Hosted

unless explicitly permitted.

## Compatibility claims

A modified implementation may claim Pico compatibility only for the protocol version and surface it actually preserves.

Examples:

- "Pico Link compatible with protocol version 0.1.7"
- "Pico Home Link compatible with protocol version 0.1.7"
- "Compatible with Pico event format version 0.1.7"

Compatibility claims must not be used to imply:

- official endorsement
- commercial hosting permission
- security certification
- production readiness
- data portability beyond the tested surfaces
- trustworthiness of the operator

## Commercial hosting names

Paid hosting, managed Pico Home services, Pico Home rental, multi-tenant Pico Home operation for money, SaaS operation and commercial support require prior written permission.

Even with protocol compatibility, a commercial hosted service may not use official-sounding Pico names without permission.

## No misleading visual identity

Forks and third-party services must not imitate official Pico visual assets, Origin Light provenance, icons, logos or official presentation in a way that misleads users.

Decorative markers may exist, but they must not imply official origin, authority, trust, host rights, policy rights, data access or endorsement.

## Origin Light and provenance

Origin Light is a decorative origin marker concept. It is not a trust score, authority marker or compatibility certificate.

Official origin proof, if implemented, must be based on verifiable provenance. It must not be forged or represented as official without permission.

## Compatibility and commercial permission are separate

Protocol compatibility does not grant commercial permission.

Commercial permission does not automatically grant compatibility status.

Trademark or naming permission does not automatically grant protocol compatibility.
