# Barrierefreiheit

Zielniveau: WCAG 2.2 AA.

## Verbindlich

- normaler Text mindestens 4,5:1 Kontrast
- großer Text und relevante UI-Grafik mindestens 3:1
- sichtbarer Tastaturfokus
- Interaktionsflächen etwa 44 × 44 px
- Status zusätzlich zu Farbe durch Symbol und Text
- vollständige Tastaturbedienung
- zugängliche Namen für Icons und Buttons
- Live-Regionen für relevante Chat- und Statusänderungen
- PICO-Ausdruck niemals als einzige Informationsquelle
