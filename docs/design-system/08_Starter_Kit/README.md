# Starter Kit

`demo.html` ist ein statisches, frameworkunabhängiges Beispiel. Es zeigt:

- Farb- und Flächenhierarchie
- PICO als visuellen Anker
- Buttons und Navigation
- Statuskarten
- Chatnachrichten und Composer
- Responsive Verhalten
- Reduced-Motion-Grundlage
- funktionierenden Light Mode und eine mobile Bottom Navigation
- Status über Farbe, unterschiedliches Symbol und Text

Die Dateien sind Ausgangspunkte, keine fertige Komponentenbibliothek. Produktionsimplementierungen müssen Semantik, Zustände und Zugänglichkeit im jeweiligen Framework ergänzen.

`styles/pico-tokens.css` importiert absichtlich die kanonische generierte
Token-Datei, statt eine zweite Kopie zu führen. Das dargestellte
`PICO_Basis_Avatar.png` ist eine Character-Referenz für diese
Design-System-Demonstration, kein allgemeines Production-Asset.
