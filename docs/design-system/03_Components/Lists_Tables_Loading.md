# Listen, Tabellen und Ladezustände

## Listen

Klare Zeilenhierarchie, 44 px Mindesthöhe, zurückhaltende Trennlinien.

## Tabellen

- sticky Header bei langen Datenbeständen
- Text links, Zahlen rechts
- Status zusätzlich als Symbol oder Text
- keine PICO-Figur pro Zeile

## Loading

- kurze Vorgänge: dezenter Spinner
- längere Vorgänge: Fortschritt oder erklärender Status
- PICO-Denkzustand nur bei echter Assistenzaktivität
- Skeletons ohne permanenten Neon-Glow
