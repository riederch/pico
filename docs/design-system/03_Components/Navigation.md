# Navigation

## Mobil

Bottom Navigation mit vier bis fünf Hauptzielen. Aktiver Zustand wird durch Hintergrund, Icon und Label vermittelt.

## Desktop

Kompakte linke Seitenleiste mit klaren Gruppen. Der PICO-Assistent wird separat geführt.

## Globaler PICO-Zugang

Kopf- oder Visieravatar in einer festen Ecke, dezente Cyan-Kontur, keine permanente starke Animation. Neue Assistenzhinweise dürfen kurz aufleuchten.
