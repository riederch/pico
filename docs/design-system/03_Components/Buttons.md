# Buttons

## Primär

- Cyan-Hintergrund
- klarer Verbtext
- mindestens 44 px Höhe
- optional führendes Icon
- dezenter Glow nur bei Fokus oder Hover

## Sekundär

- dunkle Fläche
- 1-px-Kontur
- kein dauerhafter Glow

## Tertiär

- keine eigene Fläche im Ruhezustand
- sichtbarer Fokus- und Hoverhintergrund

## Destruktiv

Rot ausschließlich für tatsächlich destruktive oder sicherheitskritische Aktionen. Feuerwehrkontext färbt normale Aktionen nicht rot.
