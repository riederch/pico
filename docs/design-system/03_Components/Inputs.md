# Eingaben und Formulare

- persistentes Label oberhalb oder innerhalb des Feldrahmens
- 14 px Radius
- klare Fokusmarkierung
- Hilfetext und Fehlertext unterhalb
- Fehler enthalten Symbol, Text und Farbe
- Placeholder ersetzt niemals ein Label
- deaktivierte Felder bleiben lesbar, aber klar nicht interaktiv
- Touch-Ziele mindestens 44 px
