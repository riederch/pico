# Karten und Panels

## Standardkarte

- optionales Icon
- Titel
- kurzer Inhalt
- eine Hauptinformation
- höchstens zwei Aktionen

## Kontextpanel

- ein Hauptsymbol
- maximal drei unterstützende Informationen
- höchstens ein kleines Diagramm
- eine Kontextfarbe

## Ausschlüsse

- dichte Dashboards in kleinen Karten
- mehrere konkurrierende Panels
- rein dekorative Linien
- PICO und mehrere Kontextobjekte gleichzeitig
