# Responsive Design und Light Mode

## Mobil

- einspaltiger Inhalt
- Bottom Navigation
- PICO reduziert und oberhalb oder unterhalb von Panels
- keine seitlichen Hologrammkompositionen

## Tablet

- flexible Zwei-Spalten-Struktur
- PICO und ein Kontextpanel können nebeneinander stehen

## Desktop

- Seitenleiste
- Hauptbereich plus optionaler Assistenzbereich
- größere Datenansichten ohne mehr dekorative Elemente

## Light Mode

Light Mode verwendet bläulich-helle Hintergründe, weiße Karten, dunkles Marine und deutlich weniger Glow. PICO bleibt auf einer neutralen oder leicht dunkleren Illustrationsfläche lesbar.
