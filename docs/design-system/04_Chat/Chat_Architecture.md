# Chat-Architektur

Der Chat besteht aus Kopfbereich, Nachrichtenverlauf, optionalem Tool-/Kontextbereich, Composer und PICO-Statusanzeige.

## Prinzipien

- Lesbarkeit vor visueller Inszenierung
- PICO-Avatar identifiziert Assistentennachrichten
- Tool-Ergebnisse sind klar von natürlicher Sprache getrennt
- Status bleibt sichtbar, aber nicht dominant
- Desktop kann einen rechten Kontextbereich verwenden; mobil erscheint er inline
