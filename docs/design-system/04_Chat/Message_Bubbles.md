# Nachrichtenblasen

## PICO

- linksbündig
- Avatar links
- dunkle bläuliche Fläche
- 18–22 px Radius
- Aktionen unterhalb
- keine Sprechblasen-Spitze

## Nutzer

- rechtsbündig
- neutralere Fläche
- kein PICO-Glow
- ausreichender Kontrast

## System

Systemmeldungen werden als kompakte Karten mit Symbol, Titel und Handlung dargestellt, nicht als scheinbare PICO-Aussage.
