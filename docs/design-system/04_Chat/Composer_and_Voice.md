# Composer und Voice-Modus

## Composer

- mehrzeilige Eingabe
- Anhänge, Sprache und Senden
- klare Fokusmarkierung
- Modusauswahl nur bei funktionalem Bedarf

## Voice-Modus

- Zuhören: Blau + Wellenform + Text
- Verarbeitung: Violett + Analyseindikator
- Ausgabe: Cyan + reduzierte Wellenbewegung
- Abbrechen bleibt jederzeit sichtbar
- Mikrofonstatus wird nicht nur durch Animation vermittelt
