# Tool- und Datenresultate

Tool-Ergebnisse erscheinen in strukturierten Karten:

- Quelle oder Toolname
- kurze Zusammenfassung
- relevante Werte
- klare Hauptaktion
- einklappbare Details

PICO fasst das Ergebnis sprachlich zusammen, ersetzt aber keine Datenquelle. Große Tabellen oder Diagramme werden nicht als Hologramm neben PICO inszeniert.
