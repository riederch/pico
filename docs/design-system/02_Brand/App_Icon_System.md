# App-Icon-System

## Haupt-App-Icon

- dunkelblauer Hintergrund
- freigegebener PICO-Kopf- oder Visier-Zuschnitt aus einem registrierten Production-Asset
- zwei vertikale Augen
- helle Kopfschale
- maximal eine Akzentfarbe
- kein Text, kein Panel, keine Ganzkörperpose

## App-Familie

Alle Familienicons verwenden denselben PICO-Kopfausschnitt, dieselbe Beleuchtung und denselben Maßstab. Ein Kontextzeichen sitzt rechts unten und belegt höchstens etwa 25 % der Iconfläche.

Die Komposition darf für kleine Flächen durch einen freigegebenen Zuschnitt
reduziert werden. PICOs Geometrie selbst wird dabei weder vereinfacht noch neu
gezeichnet. Ein Product- oder App-Icon-Entwurf wird nie rückwirkend zur
Character-Referenz.

## Größenprüfung

Jedes Icon muss bei 1024, 256, 64 und 32 px geprüft werden. Dünne Details und kleine Panels sind verboten.

## Plattform-Safe-Areas

- zentraler Inhalt innerhalb von etwa 66 % der Fläche
- keine wichtigen Details in den äußeren 10 %
- abgerundete Masken werden von der Plattform angewendet
