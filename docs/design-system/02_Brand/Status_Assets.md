# Status-Assets

Status wird durch mindestens drei Signale vermittelt:

1. Farbe
2. Symbol oder Form
3. Text beziehungsweise zugängliche Bezeichnung

## Statusfamilie

- Aktiv: Cyan + Aktivitätsindikator
- Zuhören: Blau + Wellenform
- Denken: Violett + Orbit beziehungsweise Analyseindikator
- Warnung: Amber + Warndreieck
- Blockiert: Rot + Sperr- oder Stoppsymbol
- Erfolg: Grün + Häkchen

PICO darf die gleiche Statussemantik ausdrücken, muss dabei aber die Statuslichtregel v3.2.1 vollständig einhalten.
