# Verwendung von PICO-Illustrationen

## Geeignet

- Onboarding
- Empty States
- Hilfe und Assistenz
- Bestätigung, Warnung und Fehlerbehebung
- Marketing- und Einführungsflächen

## Nicht geeignet

- als Icon für jede Tabellenzeile
- mehrfach in derselben kleinen Karte
- als dekoratives Wasserzeichen hinter Text
- als Ersatz für klare Navigation
- in einer abweichenden Stil- oder Detailstufe

## Kompositionsregel

PICO plus höchstens ein primäres Kontextobjekt. Die UI bleibt eine Stufe reduzierter als die Figur.

Jede ausgelieferte PICO-Illustration muss als zweckgebundenes
Character-Production-Asset registriert sein. Reference- und Diagnostic-Boards
dürfen Designentscheidungen belegen, aber nicht als beliebig zuschneidbare
Produktillustrationen behandelt werden.
