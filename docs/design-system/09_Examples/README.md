# Beispiele und Referenzen

Die visuellen Referenzen liegen unter `08_Starter_Kit/assets/`.

- `PICO_Designboard_Original.png`: verbindliche visuelle Herkunft und Character-Referenz.
- `PICO_Basis_Avatar.png`: kanonische neutrale Ganzkörperreferenz; wegen eingebettetem Hintergrund und Beschriftung kein allgemeines Production-Asset.
- `PICO_Regression_15er_v3.2.1.png`: diagnostischer Regressionstest. Die gemischten Statuslichtgruppen bei Feuerwehr, Erfolg und Energie sind nach dem v3.2.1-Hotfix Negativbeispiele, keine Freigaben.

Für finale Icons, Avatare und Illustrationen sind einzeln registrierte
Production-Assets aus dem Character-Workflow zu verwenden. Die verbindliche
Klassifikation steht in
`07_Governance/approved-character-assets.json`.
