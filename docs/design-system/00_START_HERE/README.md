# PICO Product Design System v1.0

Repository-Patchstand: **1.0.1**.

Dieses Paket definiert die visuelle und funktionale Produktsprache für Apps, Chats, Weboberflächen und digitale Dienste rund um PICO.

## Verbindliche Abhängigkeit

**PICO Character Design v3.2.1 bleibt unverändert der verbindliche Charakterstandard.** Das Product Design System darf PICO verwenden, aber weder seine Geometrie, Proportionen, Materialien, Identitätsmodule noch seine Statuslogik ersetzen oder neu interpretieren.

Das geprüfte Urdesign, seine SHA-256-Provenienz und die Rollen der unveränderten
Originalbilder stehen in `SOURCE.md` und
`07_Governance/approved-character-assets.json`. Nur dort ausdrücklich als
Production-Asset registrierte Einzelassets dürfen ausgeliefert werden.

## Einstieg

1. `01_Foundations/PICO_Product_Design_System_v1.0.md` lesen.
2. Design-Tokens aus `01_Foundations/tokens/` übernehmen.
3. Für App-Icons und Avatare die Regeln unter `02_Brand/` verwenden.
4. Für Chats die Spezifikation unter `04_Chat/` verwenden.
5. Vor Freigabe die Checkliste unter `07_Governance/QA_Checklist.md` durchführen.
6. Den Starter unter `08_Starter_Kit/demo.html` im Browser öffnen.

## Ziel

Eine ruhige, freundliche und technisch moderne Produktwelt, in der PICO der emotionale Anker bleibt und die Benutzeroberfläche Informationen klar, sparsam und zugänglich vermittelt.
