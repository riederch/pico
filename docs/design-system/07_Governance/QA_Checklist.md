# Freigabecheckliste

## Charakter

- [ ] PICO entspricht Character Design v3.2.1.
- [ ] Keine UI-Regel verändert den Charakter.
- [ ] Statuslichtgruppe ist vollständig einfarbig.
- [ ] Das verwendete Character-Asset ist für Oberfläche, Zustand und Größe als `production_asset` registriert.
- [ ] Ableitungsquelle und SHA-256 stimmen mit dem Character-Asset-Register überein.

## Farbe

- [ ] Marken-, Status- und Kontextfarben sind getrennt.
- [ ] Status ist nicht nur durch Farbe erkennbar.
- [ ] Kontraste erfüllen das Zielniveau.

## UI

- [ ] PICO bleibt der stärkste visuelle Anker.
- [ ] UI ist weniger detailliert als die Figur.
- [ ] Panels enthalten nur notwendige Informationen.
- [ ] Fokuszustände sind sichtbar.
- [ ] Touch-Ziele sind ausreichend groß.

## Motion und Responsive

- [ ] Reduced Motion funktioniert.
- [ ] Mobil, Tablet und Desktop wurden geprüft.
- [ ] Kleine PICO-Assets wurden aus freigegebenen Vorlagen abgeleitet.

## Inhalt

- [ ] Fehler nennen Ursache und Lösung.
- [ ] Warnungen sind sachlich.
- [ ] Icons besitzen zugängliche Bezeichnungen.
