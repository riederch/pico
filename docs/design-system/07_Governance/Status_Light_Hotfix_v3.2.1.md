# PICO Character Design v3.2.1 – Statuslicht-Hotfix

## Absolute Regel

Augen, Mundlinie, Brustkern, Antennenkugel beziehungsweise freigegebener leuchtender Kopfakzent, Unterseiten-Glow und Schwebering bilden eine untrennbare Statuslichtgruppe.

Alle Elemente dieser Gruppe verwenden in einer Darstellung exakt dieselbe Statusfarbe.

## Kontexttrennung

Kontextfarben dürfen ausschließlich Zubehör, Panels, Symbole, Werkzeuge, Helme und dezente Umgebungsakzente färben.

## Beispiele

- Erfolg: alle PICO-Statusleuchten grün.
- Warnung: alle PICO-Statusleuchten amber.
- Blockiert: alle PICO-Statusleuchten rot.
- Feuerwehr im Zustand Working: PICO cyan-blau, Helm und Einsatzpanel dürfen rote Akzente tragen.
- Energie im Zustand Working: PICO cyan-blau, Batteriepanel darf amber sein.

Eine Darstellung mit abweichend gefärbtem Schwebering oder umgefärbten Augen ist nicht freigabefähig.
